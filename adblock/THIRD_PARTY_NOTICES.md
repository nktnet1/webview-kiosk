# uBlock Origin scriptlets

The bundled runtime adapts behavior and small implementation patterns from
Raymond Hill's uBlock Origin scriptlet resources. Its upstream copyright,
GPL-3.0-or-later licence, warranty disclaimer, source references, and dated local
modification notice are preserved in the runtime and in packaged resources:

- [Runtime notice](src/main/resources/adblock/scriptlets.js)
- [Source attribution](src/main/resources/META-INF/ublock-NOTICE.txt)
- [Unchanged upstream GPL text](src/main/resources/META-INF/licenses/ublock-GPL-3.0.txt)

The user-supplied source archive identifies commit
`dfca51bea2b8605353547f605e9cffbb6dfa0789`. No extension runtime or remote executable
code is downloaded at runtime. The project's existing root licence is unchanged.
