Setting actions are accessible on the default app settings list page by clicking
the <span className="inline-flex">(<EllipsisVertical />)</span> icon.

## 1. Backups & Restore [#backups-and-restore]

When selecting `Export`, a dialog will appear showing all user settings encoded
as either `Base64` or raw `JSON`. You can either copy the text in your desired
format or save it to a file on your device.

To import your user settings, simply paste the copied text into the `Import`
input field (or load from a file) under the same format you exported with.

Content-blocking exports include the enabled setting, but not filter list
subscriptions or custom filter contents. Add those lists again after importing
settings on another device.

## 2. Device Settings [#device-settings]

Clicking the `Settings` entry here will open your device's settings
application.

Additionally, there is a `Launcher` entry that takes you directly to the
"Default Home App" device settings page, which will allow you to select your
desired launcher, e.g.

- {APP_NAME}
- One UI Home
- Nova Launcher
- Pixel Launcher

## 3. Help [#help]

This will open the {APP_NAME} Home Page in your default browser:

- https://webviewkiosk.nktnet.uk

## 4. More [#more]

This will open the `More Actions` screen.

### 4.1. Quick Access Actions [#quick-access-actions]

Open relevant device settings via intent. Buttons are listed in their screen
order, left to right and top to bottom.

| Quick Access     | Description |
|------------------|-------------|
| App Info         | Opens the application details settings for this app.<br />See [ACTION_APPLICATION_DETAILS_SETTINGS](https://developer.android.com/reference/android/provider/Settings.html#ACTION_APPLICATION_DETAILS_SETTINGS) |
| Device Settings  | Opens the main device settings screen.<br />See [ACTION_SETTINGS](https://developer.android.com/reference/android/provider/Settings.html#ACTION_SETTINGS) |
| Default Launcher | Opens the device's default launcher settings.<br />See [ACTION_HOME_SETTINGS](https://developer.android.com/reference/android/provider/Settings.html#ACTION_HOME_SETTINGS) |
| Default Apps     | Opens the default apps management screen (Android N+).<br />See [ACTION_MANAGE_DEFAULT_APPS_SETTINGS](https://developer.android.com/reference/android/provider/Settings.html#ACTION_MANAGE_DEFAULT_APPS_SETTINGS) |
| Wi-Fi Settings   | Opens the Wi-Fi settings screen.<br />See [ACTION_WIFI_SETTINGS](https://developer.android.com/reference/android/provider/Settings.html#ACTION_WIFI_SETTINGS) |
| Data Usage       | Opens the data usage settings screen (Android P+).<br />See [ACTION_DATA_USAGE_SETTINGS](https://developer.android.com/reference/android/provider/Settings.html#ACTION_DATA_USAGE_SETTINGS) |

### 4.2. Tools Actions [#tools-actions]

| Action          | Description |
|-----------------|-------------|
| Create Shortcut | Opens a dialog to create a home screen shortcut to a chosen URL, with custom labels and an automatically generated icon. |
| App Launcher    | Opens a dialog for installed apps on the device that can be launched. |

### 4.3. Manage Actions [#manage-actions]

Manage stored data and states. The four buttons form a 2×2 grid, listed here
left to right and top to bottom.

| Action           | Description |
|------------------|-------------|
| Local Files      | Opens `Web Content -> Manage Local Files`. |
| Content Blocking | Opens `Web Content -> Content Blocking`. |
| Site Permissions | Opens `Web Browsing -> Manage Site Permissions`. |
| Device Owner     | Opens `Device -> Manage Device Owner`. |

### 4.4. Clear Actions [#clear-actions]

Clear WebView or application data and cache.

| Action                     | Description |
|----------------------------|-------------|
| Cookies                    | Removes all cookies stored by the WebView, including session cookies. |
| Cache                      | Clears the WebView's cached files on disk. |
| Form Data                  | Clears saved form inputs and autofill data in the WebView. |
| History                    | Clears the WebView's browsing history and session history. |
| SSL Preferences            | Clears stored SSL certificate decisions and preferences. |
| Web Storage                | Deletes all HTML5 Web Storage (localStorage, Web SQL, IndexedDB) used by the WebView. |
