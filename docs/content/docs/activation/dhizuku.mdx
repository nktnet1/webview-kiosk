---
title: Dhizuku
description: Share an activated owner's permissions with the kiosk.
---

Use [Dhizuku](https://github.com/iamr0s/Dhizuku) when several apps need to share
an existing owner's permissions. {APP_NAME}'s Dhizuku integration needs Android
9+ and both apps installed in the same full Android user.

## 1. Connect Dhizuku [#connect]

<Steps>

<Step>

Install Dhizuku in the same user as {APP_NAME}.

</Step>

<Step>

Activate Dhizuku as Device Owner or an eligible main-user Profile Owner using
its [official activation guide](https://github.com/iamr0s/Dhizuku/discussions/19).
Installing or starting Dhizuku alone does not grant ownership.

</Step>

<Step>

Open Dhizuku and confirm it has the intended owner role.

</Step>

<Step>

Open {APP_NAME}, go to **Settings → Device → Manage Device Policies**, and
select **Request Dhizuku Permission** when available.

</Step>

<Step>

Approve the request, then check that the status card shows **Dhizuku**, the
owner's role, and the expected user scope.

</Step>

</Steps>

If Dhizuku is not detected, open it again, confirm its activation, then reopen
the Device Policies screen. See [Troubleshooting](/docs/activation/troubleshooting)
if it still does not appear.

Only the owner's existing authority is shared. Revoking permission or stopping
Dhizuku disables policy editing. Manage Dhizuku's own activation, transfer, and
removal in Dhizuku itself.
