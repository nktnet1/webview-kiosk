## 1. MDM/EMM [#mdm-emm]

If your organisation already manages the device using an MDM (Mobile Device
Management) or EMM (Enterprise Mobility Management) platform, ask your IT
administrator to add {APP_NAME} to the allowlist for Lock Task Packages.

The package name to allowlist is visible in [Settings →
About](/docs/settings/about#package-name). Typically, it is:

<Tabs items={['GitHub / F-Droid / IzzyOnDroid', 'Google Play / Aurora Store', 'Debug APK']}>
<Tab value="GitHub / F-Droid / IzzyOnDroid">

```sh
uk.nktnet.webviewkiosk
```

</Tab>
<Tab value="Google Play / Aurora Store">

```sh
com.nktnet.webview_kiosk
```

</Tab>
<Tab value="Debug APK">

```sh
uk.nktnet.webviewkiosk.debug
```

</Tab>
</Tabs>

## 2. DPC - Standalone Apps [#dpc-standalone-apps]

Below are two popular local DPC applications that can add {APP_NAME}
to the allowlist for Lock Task Packages:

1. [Test DPC](https://github.com/googlesamples/android-testdpc) (maintained by Google/Android)

   - Go to `Lock Task -> Manage lock task list`

2. [OwnDroid](https://github.com/BinTianqi/OwnDroid) (maintained by BinTianqi)

   - Go to `System -> Lock Task Mode -> Applications`

## 3. DPC - Custom Apps [#dpc-custom-apps]

If you are writing your own DPC, the kotlin code to achieve this would be:

```kt
val APP_PACKAGES = arrayOf(
  // Choose one depending on your installation method:
  "uk.nktnet.webviewkiosk",       // GitHub, F-Droid, IzzyOnDroid, etc
  "com.nktnet.webview_kiosk",     // Aurora Store, Google Play Store
  "uk.nktnet.webviewkiosk.debug", // Debug APK
)

val dpm = context.getSystemService(Context.DEVICE_POLICY_SERVICE) as DevicePolicyManager
val adminName = getComponentName(context)
// Android 8+ (API 26+): preserve packages already allowed by the DPC.
val packages = (dpm.getLockTaskPackages(adminName).toList() + APP_PACKAGES).distinct()
dpm.setLockTaskPackages(adminName, packages.toTypedArray())
```

For more information, see
[Android's official documentation](https://developer.android.com/work/dpc/dedicated-devices/lock-task-mode#allowlist_apps).
