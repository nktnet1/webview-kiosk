<Callout title="Requirements" type="warning">

This activation method requires your device to not have multiple users or any accounts registered.

For **Android 12+**, you can avoid removing users/accounts and freezing apps by
following this [XDA guide](https://xdaforums.com/t/how-i-got-device-owner-without-factory-reset.4745834/#post-90768446).
Alternatively, consider the automated [Shizuku Activation Method](/docs/activation/shizuku) (recommended).

</Callout>

## 1. Prepare the device [#prepare]

<Steps>

<Step>

Install {APP_NAME} from your chosen [download source](/docs/installation).

</Step>

<Step>

Install [Android Platform Tools](https://developer.android.com/tools/releases/platform-tools)
on your computer and enable USB debugging on the device.

</Step>

<Step>

Connect by USB, allow the debugging prompt, and run `adb devices` to confirm
the connection.

</Step>

<Step>

Check the main user. The ID is typically `0` on most devices.

```sh
adb shell pm list users
```

</Step>

</Steps>

## 2. Choose the role and installed app [#assign-owner]

Run **one** of the two owner commands in the tab matching your installation.
Choose [Profile Owner (Main User)](/docs/activation#profile-owner-work-profile)
if you also want to use a work profile. Choose Device Owner for a dedicated kiosk.

<Tabs items={['GitHub / F-Droid / IzzyOnDroid', 'Google Play / Aurora Store', 'Debug APK']}>
<Tab value="GitHub / F-Droid / IzzyOnDroid">

Device Owner:

```sh
adb shell dpm set-device-owner --user 0 uk.nktnet.webviewkiosk/.WebviewKioskAdminReceiver
```

Profile Owner:

```sh
adb shell dpm set-profile-owner --user 0 uk.nktnet.webviewkiosk/.WebviewKioskAdminReceiver
```

</Tab>
<Tab value="Google Play / Aurora Store">

Device Owner:

```sh
adb shell dpm set-device-owner --user 0 com.nktnet.webview_kiosk/uk.nktnet.webviewkiosk.WebviewKioskAdminReceiver
```

Profile Owner:

```sh
adb shell dpm set-profile-owner --user 0 com.nktnet.webview_kiosk/uk.nktnet.webviewkiosk.WebviewKioskAdminReceiver
```

</Tab>
<Tab value="Debug APK">

Device Owner:

```sh
adb shell dpm set-device-owner --user 0 uk.nktnet.webviewkiosk.debug/uk.nktnet.webviewkiosk.WebviewKioskAdminReceiver
```

Profile Owner:

```sh

```

</Tab>
</Tabs>

## 3. Check activation [#check-activation]

Open **Settings → Device → Manage Device Policies**. Confirm the expected owner
role, full-user scope, and available policies.

## 4. Troubleshooting

If you encounter activation issues regarding existing accounts, proceed with
the following steps:

<Steps>
  <Step>
    Remove all
    [additional users](https://source.android.com/docs/devices/admin/multi-user)
    on your device. You can view existing users using the command:

    ```sh
    adb shell dumpsys user | grep 'UserInfo{.*}'
    ```
    
    The goal is to only have a single main user:

    ```
    UserInfo{0:null:4c13} serialNo=0 isPrimary=true
    ```

  </Step>

  <Step>
    Find all
    [accounts](https://source.android.com/docs/automotive/users_accounts/accounts)
    on your device, e.g. in your device settings or using an application like
    [AndroidAccounts](https://github.com/iamr0s/AndroidAccounts). To also detect
    accounts in disabled applications, it's recommended that you run the command:

    ```sh
    adb shell dumpsys account list
    ```

    Our goal is to have the following in the output:

    ```
    User UserInfo{0:User:4c13}:
      Accounts: 0

      ...

      Active Sessions: 0
    ```
  </Step>

  <Step>
    Freeze all applications that uses accounts, e.g. Whatsapp. You can do this
    using an application like
    [Hail](https://github.com/aistra0528/Hail/blob/master/README_EN.md).
  </Step>

  <Step>
    Remove all accounts. If there are accounts stored in disabled applications,
    you will need to first enable them again before freezing the app and
    removing the account.
  </Step>

  <Step>
    Attempt to set {APP_NAME} as the device owner or profile owner again.
  </Step>
</Steps>

It is also worth taking a look at the
[Dhizuku activation guide](https://github.com/iamr0s/Dhizuku/discussions/19),
which includes other helpful debugging steps when setting up a device owner
application.
