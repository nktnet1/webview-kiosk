If your organisation already manages the device, ask its administrator to add
{APP_NAME} to the Lock Task allowed apps. You do not need to transfer ownership
to the kiosk or share the management app's permissions.

Find the installed package name in **Settings → About**. GitHub/F-Droid builds
normally use `uk.nktnet.webviewkiosk`. Google Play/Aurora builds use
`com.nktnet.webview_kiosk`.

## 1. Allowlist with your management app [#allowlist]

- **Test DPC:** open **Lock Task → Manage lock task list** and enable {APP_NAME}.
- **OwnDroid:** open **System → Lock Task Mode → Applications** and add the
  kiosk's installed package name.
- **Your organisation's MDM/EMM:** use its dedicated-device or kiosk allowed-apps
  policy, or ask your administrator to configure it.

Return to {APP_NAME}, lock it, and confirm it uses Lock Task rather than screen
pinning. The external management app retains control of the allowlist.
Unavailable policy-editing controls in the kiosk are normal when permissions
have not been shared.

See [Security](/docs/security#external-dpc-lock-state) for lock-state behaviour.
