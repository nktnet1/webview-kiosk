title: Factory Reset and QR Code
description: Set up a fresh dedicated kiosk with Device Owner.

This is the recommended method for a new dedicated kiosk. QR provisioning needs
Android 7+ and a device that is new or has been factory-reset.

<Callout title="Back up before resetting" type="warning">

A factory reset removes local apps and data. Back up anything you need and make
sure you can satisfy any account verification required after the reset.

</Callout>

## Set up the kiosk [#setup]

1. Start a new device, or factory-reset it using Android Settings.
2. At the initial welcome screen, tap the same spot six times to open QR setup.
3. Connect to Wi-Fi if asked. Some devices download a QR scanner first.
4. Open the [QR Installation tool](/tools/qr-installation) on another screen.
   Choose the download source and settings, then generate the QR code.
5. Scan the code with the device and complete the setup wizard.
6. Open **Settings → Device → Manage Device Policies** and confirm **Device Owner**.

The QR tool provisions Device Owner. It does not assign Profile Owner to your
existing main user. For that role, use [Shizuku](/docs/activation/shizuku) or
[ADB](/docs/activation/adb).

If QR setup is unavailable on your device, check its manufacturer's enrollment
instructions or use [another activation method](/docs/activation).
