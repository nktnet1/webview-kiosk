## 1. Choose an owner role [#choose-owner-role]

| Role | Use it when |
| --- | --- |
| Device Owner | You are setting up a dedicated kiosk without a work profile. |
| Profile Owner in the main user | You want kiosk policies in the personal user alongside a separate work profile. |
| Shared owner through Dhizuku | You want Dhizuku to share its owner permissions with several apps. |
| MDM/EMM | Your organisation already manages the device and can allowlist the kiosk. |

### 1.1. Profile Owner and work profiles [#profile-owner-work-profile]

Choosing **Profile Owner for the main user** lets you keep or create a separate
work profile. **Device Owner** prevents adding a work profile.

First activate Profile Owner using [Shizuku](/docs/activation/shizuku) or
[ADB](/docs/activation/adb). You can then create a work profile using your work-profile
app or the optional ADB example below. The example uses main user `0`.

<Accordions type="single">
<Accordion title="Optional ADB example: add a work profile">

<Steps>

<Step>

Create the work profile:

```sh
adb shell pm create-user --profileOf 0 --managed Work
```

</Step>

<Step>

Note the new profile ID printed by Android. The following examples use `10`.
Replace every `10` with the actual new profile ID.

</Step>

<Step>

Start the profile and install the work copy using the tab matching your app:

<Tabs items={['GitHub / F-Droid / IzzyOnDroid', 'Google Play / Aurora', 'Debug APK']}>
<Tab value="GitHub / F-Droid / IzzyOnDroid">

```sh
adb shell am start-user 10
adb shell pm install-existing --user 10 uk.nktnet.webviewkiosk
adb shell dpm set-profile-owner --user 10 uk.nktnet.webviewkiosk/.WebviewKioskAdminReceiver
adb shell am start --user 10 -n uk.nktnet.webviewkiosk/.MainActivity
```

</Tab>

</Tab>

## 2. Choose an activation method [#choose-method]

| Method | Requirements | Best for |
| --- | --- | --- |
| [Shizuku](/docs/activation/shizuku) | Android 12+ with Shizuku running | Activation from the app on an existing device. |
| [ADB](/docs/activation/adb) | A computer with Android Platform Tools | Setting Device Owner or main-user Profile Owner directly. |
| [QR Code](/docs/activation/qr-code) | Android 7+ on a new or reset device | A fresh dedicated kiosk with Device Owner. |
| [Dhizuku](/docs/activation/dhizuku) | Android 6+ with Dhizuku activated | Sharing an existing owner's permissions. |
| [MDM/EMM](/docs/activation/external-dpc) | Access to your management platform | Allowlisting the kiosk without changing ownership. |

After activation, open **Settings → Device → Manage Device Policies** and check
the role and available Lock Task policies. If setup fails, see
[Troubleshooting](/docs/activation/troubleshooting).
