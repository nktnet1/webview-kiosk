## 1. Choose an owner role [#choose-owner-role]

| Role | Use it when |
| --- | --- |
| Device Owner | You are setting up a dedicated kiosk without a work profile. |
| Profile Owner in the main user | You want kiosk policies in the personal user alongside a separate work profile. |
| Shared owner through Dhizuku | You want Dhizuku to share its device or profile owner permissions with several apps. |
| MDM/EMM | Your organisation already manages the device and can allowlist the kiosk. |

### 1.1. Profile Owner and work profiles [#profile-owner-work-profile]

Choosing **Profile Owner (Main User)** lets you keep or create a separate
work profile, which is disallowed in **Device Owner** mode.

For example, this can be done via ADB:

<Steps>

<Step>

Find the ID of your main user (typically `0`)

```sh
adb shell pm list users
```

</Step>

<Step>

Create the work profile based on the main user's ID (in this case, `0`):

```sh
adb shell pm create-user --profileOf 0 --managed Work
```

Note the new profile ID printed by Android. In this example, we will use `10`.

</Step>

<Step>

Start the profile and install the work copy using the tab matching your app:

<Tabs items={['GitHub / F-Droid / IzzyOnDroid', 'Google Play / Aurora Store', 'Debug APK']}>
<Tab value="GitHub / F-Droid / IzzyOnDroid">

```sh
adb shell am start-user 10
adb shell pm install-existing --user 10 uk.nktnet.webviewkiosk
adb shell dpm set-profile-owner --user 10 uk.nktnet.webviewkiosk/.WebviewKioskAdminReceiver
adb shell settings --user 10 put secure user_setup_complete 1
adb shell am start --user 10 -n uk.nktnet.webviewkiosk/.MainActivity
```

</Tab>
<Tab value="Google Play / Aurora Store">

```sh
adb shell am start-user 10
adb shell pm install-existing --user 10 com.nktnet.webview_kiosk
adb shell dpm set-profile-owner --user 10 com.nktnet.webview_kiosk/uk.nktnet.webviewkiosk.WebviewKioskAdminReceiver
adb shell settings --user 10 put secure user_setup_complete 1
adb shell am start --user 10 -n com.nktnet.webview_kiosk/uk.nktnet.webviewkiosk.MainActivity
```

</Tab>
<Tab value="Debug APK">

```sh
adb shell am start-user 10
adb shell pm install-existing --user 10 uk.nktnet.webviewkiosk.debug
adb shell dpm set-profile-owner --user 10 uk.nktnet.webviewkiosk.debug/uk.nktnet.webviewkiosk.WebviewKioskAdminReceiver

# Needed for work apps to appear in "Recents"
adb shell settings --user 10 put secure user_setup_complete 1

adb shell am start --user 10 -n uk.nktnet.webviewkiosk.debug/uk.nktnet.webviewkiosk.MainActivity
```

</Tab>
</Tabs>

Make sure to replace `10` with the ID returned from the previous step.

</Step>

</Steps>

## 2. Choose an activation method [#choose-method]

| Method | Requirements | Best for |
| --- | --- | --- |
| [Shizuku](/docs/activation/shizuku) | Android 12+ with Shizuku running | Activation from the app on an existing device. |
| [ADB](/docs/activation/adb) | A computer with Android Platform Tools | Setting Device Owner or main-user Profile Owner directly. |
| [QR Code](/docs/activation/qr-code) | Android 7+ on a new or reset device | A fresh dedicated kiosk with Device Owner. |
| [Dhizuku](/docs/activation/dhizuku) | Android 6+ with Dhizuku activated | Sharing an existing owner's permissions. |
| [MDM/EMM/DPC](/docs/activation/mdm-emm-dpc) | Access to your management platform | Allowlisting the kiosk without changing ownership. |

After activation, open **Settings → Device → Manage Device Policies** and check
the role and available Lock Task policies.
