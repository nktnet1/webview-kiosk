A work profile is optional and separate from main-user Profile Owner. The work
copy has its own app data and permissions; it cannot automatically control the
personal user or lock the whole device.

For a kiosk in your main user, follow [ADB](/docs/activation/adb) or
[Shizuku](/docs/activation/shizuku) instead. The in-app Shizuku action does not
create or activate a work profile.

## Create a separate work copy [#create-work-profile]

Use this advanced ADB method only if your device permits another managed
profile. The example uses main user `0`; substitute your main user ID if needed.

```sh
adb shell pm create-user --profileOf 0 --managed Work
```

Note the new profile ID printed by Android. The following examples use `10`;
replace every `10` with the actual new profile ID.

<Tabs items={['GitHub / F-Droid / IzzyOnDroid', 'Google Play / Aurora', 'Debug APK']}>
<Tab value="GitHub / F-Droid / IzzyOnDroid">

```sh
adb shell am start-user 10
adb shell pm install-existing --user 10 uk.nktnet.webviewkiosk
adb shell dpm set-profile-owner --user 10 uk.nktnet.webviewkiosk/.WebviewKioskAdminReceiver
adb shell am start --user 10 -n uk.nktnet.webviewkiosk/.MainActivity
```

</Tab>
<Tab value="Google Play / Aurora">

```sh
adb shell am start-user 10
adb shell pm install-existing --user 10 com.nktnet.webview_kiosk
adb shell dpm set-profile-owner --user 10 com.nktnet.webview_kiosk/uk.nktnet.webviewkiosk.WebviewKioskAdminReceiver
adb shell am start --user 10 -n com.nktnet.webview_kiosk/uk.nktnet.webviewkiosk.MainActivity
```

</Tab>
<Tab value="Debug APK">

```sh
adb shell am start-user 10
adb shell pm install-existing --user 10 uk.nktnet.webviewkiosk.debug
adb shell dpm set-profile-owner --user 10 uk.nktnet.webviewkiosk.debug/uk.nktnet.webviewkiosk.WebviewKioskAdminReceiver
adb shell am start --user 10 -n uk.nktnet.webviewkiosk.debug/uk.nktnet.webviewkiosk.MainActivity
```

</Tab>
</Tabs>

A compatible DPC or MDM can also provision a separate work profile. The
[QR Installation tool](/tools/qr-installation) is for Device Owner enrollment,
so it does not replace this workflow.
