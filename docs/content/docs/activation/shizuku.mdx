## 1. Requirements [#requirements]

<Callout title="Account workaround on Android 12+" type="info">

On Android 12+, activation attempts the setup-state workaround outlined in this
[XDA guide](https://xdaforums.com/t/how-i-got-device-owner-without-factory-reset.4745834/#post-90768446).
The app restores the original setup state after the attempt. Android and OEM
ownership restrictions can still prevent activation.

</Callout>

Your device should be running **Android 6+** with
[Shizuku](https://shizuku.rikka.app/download/)
active. For more details, refer to
[Shizuku's User Manual](https://shizuku.rikka.app/guide/setup/).

On Android 6-11, activation uses the normal Android ownership commands without
changing setup state. Existing accounts or ownership can prevent activation -
follow the [ADB activation guide](/docs/activation/adb) if Android rejects it.

Activate from the device's main user (typically id 0). Automatic activation is
unavailable on headless-system-user devices prior to Android 14, since the main
user cannot be idenfied by {APP_NAME}.

## 2. Activate ownership [#activate]

<Steps>

<Step>

In {APP_NAME}, open **Settings → Device → Manage Device Policies → Activate with Shizuku**.

</Step>

<Step>

Select either **Device Owner** or **Profile Owner**, then tap **Activate**.

</Step>

<Step>

Allow {APP_NAME} access when Shizuku asks. Keep Shizuku running until the result appears.

</Step>

<Step>

Check the Device Policies card for the owner role and available Lock Task policies.

</Step>

<Step>

Open the Shizuku app and revoke the permission granted to {APP_NAME} - it is no
longer needed after activating device owner or profile owner.

</Step>

</Steps>
