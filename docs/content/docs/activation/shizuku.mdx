<Callout title="Activate without removing accounts or freezing apps" type="success">

The activation method below automates the process outlined in the following
[XDA guide](https://xdaforums.com/t/how-i-got-device-owner-without-factory-reset.4745834/#post-90768446).

</Callout>

## 1. Requirements [#requirements]

Your device should be running **Android 12+** with
[Shizuku](https://shizuku.rikka.app/download/)
active. For more details, refer to
[Shizuku's User Manual](https://shizuku.rikka.app/guide/setup/).

## 2. Activate ownership [#activate]

<Steps>

<Step>

In {APP_NAME}, open **Settings → Device → Manage Device Policies → Activate with Shizuku**.

</Step>

<Step>

Select either **Device Owner** or **Profile Owner**, then tap **Activate**.

</Step>

<Step>

Allow {APP_NAME} access when Shizuku asks. Keep Shizuku running until the result appears.

</Step>

<Step>

Check the Device Policies card for the owner role and available Lock Task policies.

</Step>

<Step>

Open the Shizuku app and revoke the permission granted to {APP_NAME} - it is no
longer needed after activating device owner or profile owner.

</Step>

</Steps>
