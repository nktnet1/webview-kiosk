## 1. Requirements [#requirements]

Requires **Android 12+** with [Shizuku](https://shizuku.rikka.app/download/) running.
Follow [Shizuku's startup guide](https://shizuku.rikka.app/guide/setup/) to start it.
Use {APP_NAME} in the main Android user, usually ID `0`.

<Callout title="Activate without removing accounts" type="info">

For activation with existing accounts, see the
[XDA guide](https://xdaforums.com/t/how-i-got-device-owner-without-factory-reset.4745834/#post-90768446).

</Callout>

## 2. Activate ownership [#activate]

<Steps>

<Step>

Open **Settings → Device → Manage Device Policies → Activate with Shizuku**.

</Step>

<Step>

Choose **Device Owner** or **Profile Owner**, then tap **Activate**.

</Step>

<Step>

Allow {APP_NAME} access when Shizuku asks. Keep Shizuku running until the result appears.

</Step>

<Step>

Check the Device Policies card for the owner role and available Lock Task policies.

</Step>

</Steps>

After activation, Shizuku can be stopped.

## 3. If activation fails [#activation-fails]

Follow the result message, or select **Show details** to inspect Android's response.
See [Troubleshooting](/docs/activation/troubleshooting) for help.
