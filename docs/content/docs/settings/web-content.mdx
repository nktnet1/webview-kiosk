## 1. Home URL [#home-url]

Configure the Home URL, which can be returned to as per <a href="/docs/settings/web-browsing/#allow-go-home">`Web Browsing -> Allow Go Home`</a>.

**Default:** https://webviewkiosk.nktnet.uk

## 2. Blacklist & Whitelist Regex [#blacklist-and-whitelist-regex]

Specify regular expressions (regex), one per line. URL rules use the
[RE2](https://github.com/google/re2/wiki/syntax) regex engine. Test complex
patterns before deploying them, as RE2 does not guarantee cheap compilation.

<Callout title="Upgrading from 0.26.26 or earlier" type="warn">

URL rules previously used Android's Java regex engine. RE2/J does not support
lookahead, lookbehind, or backreferences. Review existing blacklist and whitelist
rules before upgrading, including rules supplied through managed configurations.
Unsupported or invalid blacklist rules fail closed when evaluated and can
block navigation with a `URL_REGEX_ERROR` page. Invalid whitelist rules do not
block URLs on their own, but cannot override a blacklist rule. A matching valid
whitelist rule still takes precedence.

Use the [Regex Playground](/tools/regex) to check replacement rules before
deploying them.

</Callout>

The app rejects malformed navigation URLs. Normal navigation URLs, including
website redirects and decoded block-page or PDF viewer targets, are limited to
2,097,152 characters. Data URLs may contain up to 20,971,520 characters. Internal
PDF viewer URLs may be longer to hold an encoded source URL; the decoded source
must still satisfy its own limit. Block-page and PDF wrappers are limited to ten
combined levels.

Escaping is required for special characters in regex like `.` and `?`.

These patterns also use partial matching. If you need strict control, anchor
your regex with `^` and `$`.

Whitelist patterns take precedence over blacklist patterns.

**Default:** (blank)

### 2.1. Blacklist Example [#blacklist-example]

Block all:

```
.*
```

Block google, including all subdomains and paths:

```
^https://.*\.?google\.com/?.*
```

### 2.2. Whitelist Example [#whitelist-example]

Allow the `https://trusted.org` home page, as well as its subdomains and paths, to bypass the blacklist:
```
^https://trusted\.org(/.*)?$
^https://.*\.trusted\.org(/.*)?$
```

## 3. Bookmarks [#bookmarks]

Specify bookmarked URLs one per line. Blank lines will be ignored.

This is accessible in the address bar. See the relevant setting `Web Browsing -> Allow Bookmark Access`.

You can also specify a title for display in the format: `<URL> | <Title>`.

For example:

```log
https://webviewkiosk.nktnet.uk | Webview Kiosk

https://duckduckgo.com | DuckDuckGo

https://f-droid.org | F-Droid
```

**Default:** (blank)

## 4. Support PDF Rendering [#support-pdf-rendering]

Set to true to support PDF Rendering using Mozilla's PDF.js renderer:

- https://github.com/mozilla/pdf.js

You will first need to download the renderer by opening the popup menu for this
setting and clicking the `Download PDF.js assets` button.

Remote PDF files are loaded through a dummy endpoint:

- https://pdf-dummy.webviewkiosk.nktnet.uk?wk_pdf_url=[SAMPLE_PDF_URL].pdf

which gets locally routed to the downloaded PDF.js renderer using the
WebViewAssetLoader API:

- https://developer.android.com/reference/androidx/webkit/WebViewAssetLoader

**Default:** false

## 5. Allow Local Files [#allow-local-files]

Allow the WebView to open local files such as HTML, PDF, images, audio, video
and text. Upload and manage these files under
**Settings → Web Content → Manage Local Files**.

When this setting is enabled, open the uploaded files from the **Files** action
in the address bar menu <span className="inline-flex">(<EllipsisVertical />)</span>
or the kiosk control panel (if that action is configured).

**Default:** true

## 6. Enable Content Blocking [#enable-content-blocking]

Enable to block ads, malware and trackers using filter lists.

In **Settings → Web Content → Content Blocking**, you can add lists of the following types:

| Type | Description |
|---|---|
| **Preset** | Choose a ready-made list from uBlock Origin, EasyList, AdGuard or HaGeZi |
| **URL** | Add a filter list using its HTTP or HTTPS address |
| **Custom** | Paste your own blocking rules or import a text file |

**Default:** true
